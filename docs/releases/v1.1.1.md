# v1.1.1

Maintenance release focused on session lifecycle correctness and dashboard security. See `CHANGELOG.md` for the full list.

## Fixed

- **Zombie-session resurrection (sessions 355/356 incident):** `touch_session` refuses to update heartbeats on terminal session rows, so a hung process waking after reconciliation can no longer push `last_heartbeat_at` past `ended_at`.
- **Live sessions marked stale after laptop sleep (root cause of 355/356):** the cleanup loop detects that it woke far later than scheduled and skips that round, giving heartbeats time to catch up.
- **Duplicate session summaries:** `finalize_active_session` re-reads the authoritative DB row before writing a summary.
- **Heartbeat writes into dead sessions:** the heartbeat loop touches first and detaches a session closed elsewhere, so the next tool call starts a fresh session.
- **MCP prompt compatibility (OpenCode crash):** prompts now return `PromptResult([Message(...), ...])` instead of plain dicts; numeric prompt parameters accept strings and coerce safely.
- **Dashboard API 500s:** `_get_events` now passes the required `project_path` argument, fixing every `/api/*` endpoint.

## Security

- **GitPython 3.1.50 → 3.1.62** (HIGH): closes 15 advisories including a CVSS 9.3 conditional RCE via `clone_from` option-injection.
- **cryptography 49.0.0 → 50.0.1** (MEDIUM): closes CVE-2026-69247 (PKCS#7 EnvelopedData decryption oracle).
- **Dashboard authentication:** `allbrain ui` now requires a bearer token on all `/api/*` endpoints. A fresh random token is generated per start; set `ALLBRAIN_DASHBOARD_TOKEN` to pin your own. `/` and `/health` stay open.
- **Dashboard CORS:** blanket `Access-Control-Allow-Origin: *` removed; origins must be allowlisted via `ALLBRAIN_DASHBOARD_ALLOWED_ORIGINS`.
- **Dashboard `limit` validation:** `/api/events?limit=` rejects non-integer and out-of-range values with a 400 instead of crashing.

```shell
uvx allbrain-agent-runtime install --codex
```
